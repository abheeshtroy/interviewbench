# InterviewBench

InterviewBench lets hiring teams test an AI screening-agent release against synthetic candidate scenarios before it reaches real candidates.

This first slice compares a baseline and proposed agent for a Senior Backend Engineer role. It shows aggregate agreement separately from non-negotiable release gates, then explains a failed case with the evidence behind it. All data in this project is synthetic.

## Run locally

```sh
npm install
npm run dev
```

Run checks with `npm run format:check`, `npm run typecheck`, and `npm test`.
